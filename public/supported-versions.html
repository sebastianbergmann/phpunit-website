Bugfix Support

Bugfix Support means that bugs will be fixed for a version of PHPUnit. Bugfix Support for major version X ends two years after its initial release (when major version (X+2) is released). Bugfix Support for minor version X.Y ends when minor version X.(Y+1) is released.

The table above therefore names one minor version for each major version: this is the only one that changes are still made for. New major and minor versions are released according to a fixed release schedule.

Life Support

When Bugfix Support ends for a major version, Life Support for this major version begins.

Life Support means that changes will be made for an otherwise unsupported version of PHPUnit to be compatible with new versions of PHP. Life Support ends when an old version of PHPUnit cannot be made compatible with a new version of PHP without breaking backward compatibility.

PHP Compatibility

A version of PHPUnit that is compatible with a newer version of PHP runs on that version of PHP. It does not support the language features that were introduced after the version of PHP that it requires.

For example, PHPUnit 8.5 requires PHP 7.2 and runs on PHP 8, where it works for PHP code that is compatible with PHP 7.2. Its test double code generator does not support union types, however, which were introduced in PHP 8.

Older Versions

This support policy has been in effect since PHPUnit 4. For PHPUnit 1, PHPUnit 2, and PHPUnit 3, the dates shown above are those of their respective last releases. Note that PHPUnit 1 (for PHP 4) and PHPUnit 2 (for PHP 5) were developed in parallel and are not successive major versions.

Upgrading

The article Upgrading PHPUnit should be boring explains how to get from one major version of PHPUnit to the next: in which order to work, and which of PHPUnit's two lists of deprecations to read along the way.
